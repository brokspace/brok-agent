# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.1] - 2026-10-30

### Fixed

- The log names the workspace root repository `.` instead of `""`
  (`tracking git repositories repositories=["."]`).

## [0.2.0] - 2026-10-25

### Added

- Follow-up questions: `agent:ask` uses the conversation history sent by `brok chat` (last 12 turns,
  about 12 000 characters), and short follow-ups reuse the previous question for retrieval.
- Multi-repo workspaces: independent git repositories nested in the workspace (up to four levels deep)
  are tracked like submodules, also when the workspace root is not a repository; new clones are found
  within a minute.

### Changed

- The tracker follows each repository's `HEAD`: files changed by commits, pulls, checkouts and rebases
  are published as `file:changed`, so the index no longer goes stale after switching branches.
- Folders generated by brok (`.brokspace-managed` marker, e.g. exported skills) are ignored.
- `shard.json` no longer pins v0.1.0 release binaries; the v0.2.0 binaries are pinned after release.

## [0.1.0] - 2026-10-24

### Added

- Incremental change tracking through `git diff --name-only HEAD` and `git ls-files --others`, across the
  root repository and every initialized submodule; publishes `file:changed`.
- Optional pre-indexation LLM review of changed files selected by glob filters; publishes `review:result`.
- `agent:ask` handler: hybrid search through the core index service, Markdown context assembly within a
  character budget, secret redaction, and streamed answers (`agent:ask.chunk` → `agent:ask.done`).
- OpenAI-compatible chat completions client with a robust incremental SSE parser (Ollama, LM Studio,
  Anthropic, DeepSeek, OpenAI, vLLM, ...).
- Prompt validation and redaction of AWS, GitHub, Slack, `sk-` style keys, PEM private keys and
  `password = "..."` style assignments.
